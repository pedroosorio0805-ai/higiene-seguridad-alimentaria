# Higiene & Seguridad Alimentaria

Sitio educativo y adaptable a computadoras, tabletas y celulares.

## Archivos
- `index.html`: contenido.
- `style.css`: diseño.
- `script.js`: menú para celulares.
- `img/`: carpeta para imágenes locales opcionales.

## Abrir en Windows
1. Descomprime el ZIP.
2. Abre la carpeta.
3. Haz doble clic en `index.html`.

Las fotografías y tipografías se cargan desde internet. El contenido, estilos y menú funcionan localmente.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `higiene-seguridad-alimentaria`.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `img` a la raíz.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`. Guarda.
6. Abre la dirección que GitHub Pages te muestre.

Cambia `[Nombre del alumno]` en `index.html` por el crédito que corresponda. Este material es educativo general; en actividades reales, sigue la normativa sanitaria aplicable y las indicaciones del establecimiento.
